2b:Tb38,<h2 id="project-overview">Project Overview</h2>
<p>Boot Factory is an e-commerce web application developed as coursework using the ASP.NET MVC framework and C#. The project demonstrates my ability to build scalable, secure, and user-friendly web applications from the ground up. The platform allows users to browse a catalogue of footwear products, add items to their shopping basket, and proceed through a complete checkout process.</p>
<h2 id="technical-stack">Technical Stack</h2>
<ul>
<li><strong>Backend</strong>: C# with ASP.NET MVC framework</li>
<li><strong>Frontend</strong>: HTML5, CSS3, Bootstrap for responsive design</li>
<li><strong>Database</strong>: SQL Server for product data and user management</li>
<li><strong>Authentication</strong>: ASP.NET Identity for secure user login and registration</li>
<li><strong>Version Control</strong>: Git for source code management</li>
</ul>
<h2 id="key-features-implemented">Key Features Implemented</h2>
<ul>
<li><strong>User Authentication System</strong>: Secure login, registration, and user profile management with email confirmation</li>
<li><strong>Product Catalogue</strong>: Categorized browsing with filtering and search functionality</li>
<li><strong>Shopping Basket</strong>: AJAX-powered add/remove functionality with real-time total calculation</li>
<li><strong>Order Processing</strong>: Complete checkout flow with address collection and order confirmation</li>
<li><strong>Admin Dashboard</strong>: Product management interface for adding, editing, and removing products</li>
<li><strong>Responsive Design</strong>: Mobile-friendly interface that adapts to different screen sizes</li>
</ul>
<h2 id="development-challenges">Development Challenges</h2>
<p>The most significant challenges I encountered during development included implementing session management for the shopping basket functionality and ensuring proper validation of user input throughout the application.
