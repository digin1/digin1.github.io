28:T975,<h2 id="project-overview">Project Overview</h2>
<p>A production-grade web application for neuroscience researchers to generate brain region heatmaps from experimental data. Supports multiple species brain templates and provides real-time interactive controls for colour mapping, range adjustment, and export.</p>
<h2 id="project-details">Project Details</h2>
<h3>Technologies Used</h3>
<ul>
<li>Next.js 16 with React 19 (TypeScript)</li>
<li>D3.js v7 (SVG-based brain atlas rendering)</li>
<li>Zustand (state management)</li>
<li>Tailwind CSS 4</li>
<li>Vitest + React Testing Library (73 passing tests)</li>
<li>Flask 2.3 (Python backend)</li>
<li>pandas, NumPy, Matplotlib, lxml, BeautifulSoup4</li>
</ul>
<h3>Key Features</h3>
<ul>
<li><strong>Multiple Brain Templates</strong>: DevMouse, Mouse, Rat, Human — switchable in real-time</li>
<li><strong>10+ Scientific Colormaps</strong>: Viridis, Plasma, Inferno, Magma, Cividis, Turbo, Cool, Warm, RdYlBu, Spectral</li>
<li><strong>Data Upload</strong>: CSV/Excel upload with validation, error messages, and typo suggestions for region names</li>
<li><strong>Interactive Controls</strong>: Real-time range adjustment, colour selection, linear/log scale toggle</li>
<li><strong>Dual Export</strong>: PNG (raster) and SVG (vector) for publication-quality figures</li>
<li><strong>Responsive Design</strong>: Works across desktop and tablet browsers</li>
<li><strong>CI/CD</strong>: Automated deployment to GitLab Pages on push to main</li>
</ul>
<h3>Testing</h3>
<ul>
<li>73 passing tests covering data processing, colour mapping, region matching, and export functionality</li>
</ul>
<h2 id="technical-highlights">Technical Highlights</h2>
<ul>
<li><strong>D3.js SVG Rendering</strong>: Dynamic colouring of brain atlas SVG regions based on uploaded data values</li>
<li><strong>Intelligent Validation</strong>: Fuzzy matching suggests corrections for mistyped brain region names</li>
<li><strong>Full-Stack</strong>: Next.js frontend communicates with Flask API for data processing and SVG template management</li>
<li><strong>Production Deployment</strong>: GitLab CI/CD pipeline with automated build, test, and deploy stages</li>
</ul>
<h2 id="impact">Impact</h2>
