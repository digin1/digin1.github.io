26:T11a7,<h2 id="project-overview">Project Overview</h2>
<p>CageSense is a web-based colony management system built for the Grant Lab at the University of Edinburgh to manage all aspects of a transgenic mouse breeding facility. It replaces spreadsheet-based tracking with a centralised database, AI-powered query interface, automated reporting, and full audit logging for regulatory compliance.</p>
<h2 id="project-details">Project Details</h2>
<h3>Technologies Used</h3>
<ul>
<li>Next.js 15 (React 19, TypeScript)</li>
<li>FastAPI (async Python backend)</li>
<li>PostgreSQL 16 (SQLAlchemy 2.0 with asyncpg)</li>
<li>OpenAI Agents Python SDK (multi-agent orchestration)</li>
<li>Celery + Redis (async job queue with scheduled tasks)</li>
<li>Alembic (database migrations)</li>
<li>Docker Compose (8 orchestrated services)</li>
<li>Nginx (reverse proxy)</li>
<li>TanStack React Table + React Query</li>
<li>Recharts (data visualisation)</li>
<li>Zustand (state management)</li>
<li>JWT + bcrypt (authentication)</li>
<li>Playwright (E2E testing)</li>
</ul>
<h3>Architecture</h3>
<p>8 Docker Compose services on a custom bridge network:</p>
<ol>
<li><strong>Nginx</strong> — Reverse proxy (port 8080)</li>
<li><strong>Frontend</strong> — Next.js 15 application</li>
<li><strong>Backend</strong> — FastAPI with async SQLAlchemy</li>
<li><strong>PostgreSQL</strong> — Persistent database</li>
<li><strong>Redis</strong> — Cache and Celery message broker</li>
<li><strong>Celery Worker</strong> — Async job processor</li>
<li><strong>Celery Beat</strong> — Scheduled task scheduler (daily reports)</li>
<li><strong>Health Checks</strong> — Monitoring across all services</li>
</ol>
<h3>Key Features</h3>
<h4>Core Data Management</h4>
<ul>
<li><strong>Mouse Tracking</strong>: Unique IDs, sex, DOB/DOD, ear marks, genotype, status lifecycle (alive → in_mating → culled/dead/transferred)</li>
<li><strong>Breeding Lines</strong>: Background strains, colony codes, gene/clone info, active/frozen status</li>
<li><strong>Mating Records</strong>: Setup, plugging, litter tracking with pup counts by sex</li>
<li><strong>Cage Management</strong>: Occupancy monitoring, location tracking, line association</li>
<li><strong>Genotype Tracking</strong>: Homozygous, heterozygous, wild-type distribution with allele management</li>
<li><strong>Cryopreservation</strong>: Frozen sperm/embryo sample tracking</li>
</ul>
<h4>AI Chat Assistant</h4>
<ul>
<li>Natural language queries against the colony database (no SQL needed)</li>
<li><strong>OpenAI Agents SDK</strong> with multi-agent orchestration and guardrails</li>
<li>Staged proposed updates — AI suggests changes, researchers approve in the UI</li>
<li>File attachments with OCR support (Excel, PDF, images)</li>
<li>Streaming responses via Server-Sent Events</li>
<li>Execution logging and response quality tripwires</li>
