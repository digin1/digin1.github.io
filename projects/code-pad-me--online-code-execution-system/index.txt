<h2 id="about-the-project">🚀 About the Project</h2>
<p><strong>Code-Pad.me</strong> is an online code execution web platform designed to help learners, educators, and developers write, share, and execute code effortlessly from any device—without the need to install a local compiler or development environment.</p>
<p>Whether you're coding from a desktop, tablet, or even a mobile browser, Code-Pad.me empowers users to share challenges, test code snippets, and learn collaboratively—all within a sleek, browser-based interface.</p>

<h2 id="inspiration">🧠 Inspiration</h2>
<p>During the COVID-19 pandemic, e-learning became a lifeline for education. However, coding education suffered due to setup issues—like incompatible compilers, platform dependencies, and device limitations (especially for iOS users).<br>
This inspired me to develop <strong>Code-Pad.me</strong>—a zero-setup, responsive, cloud-based code runner that works anywhere, anytime.</p>
<hr>
<h2 id="project-goals">🎯 Project Goals</h2>
<ul>
<li>Build a <strong>web-based code execution platform</strong> supporting multiple programming languages.</li>
<li>Eliminate setup barriers by offering <strong>compiler-less code execution</strong>.</li>
<li>Enable users to <strong>create and share coding challenges</strong> for peer learning.</li>
<li>Encourage coding collaboration with <strong>shareable links &#x26; QR codes</strong>.</li>
<li>Ensure cross-platform access with a <strong>responsive, mobile-first design</strong>.</li>
</ul>
<hr>
<h2 id="key-features">💡 Key Features</h2>
<ul>
<li>🖥️ <strong>Multi-language Code Execution</strong> (via Judge0 API)</li>
<li>🔒 <strong>Secure, Containerized Execution</strong> (Docker-based sandboxing)</li>
<li>📱 <strong>Mobile &#x26; Desktop Friendly</strong> (Responsive UI using Bootstrap 5)</li>
<li>📤 <strong>Code Sharing with QR &#x26; Short URLs</strong></li>
<li>🎯 <strong>Custom &#x26; Random Challenges</strong> for continuous learning</li>
<li>📥 <strong>Downloadable Code</strong> with proper file extensions</li>
<li>🔢 <strong>Code View Metrics</strong> to track engagement</li>
<li>💬 <strong>User Feedback Integration</strong> during development</li>
</ul>
<hr>
<h2 id="architecture-overview">🏗️ Architecture Overview</h2>
<p>The app uses a modern stack with continuous delivery pipelines:</p>
<ul>
<li><strong>Backend</strong>: Python (Django)</li>
<li><strong>Frontend</strong>: Bootstrap, JavaScript, JQuery, CodeMirror Editor</li>
<li><strong>API</strong>: Judge0 for secure multi-language code execution</li>
<li><strong>CI/CD</strong>: GitLab Runner, Docker</li>
<li><strong>Database</strong>: SQLite (Dev), PostgreSQL (Production)</li>
<li><strong>Deployment</strong>: Docker containers on Ubuntu VM</li>
</ul>
<hr>
<h2 id="testing-and-evaluation">🧪 Testing &#x26; Evaluation</h2>
<ul>
<li>✅ <strong>Unit &#x26; System Testing</strong>: Validated core functionality, user interactions, and system behavior.</li>
<li>📈 <strong>Performance Testing</strong>: Tested with up to 1000 concurrent users using <code>httperf</code>.</li>
<li>📋 <strong>User Feedback Surveys</strong>: Guided feature additions like:
<ul>
<li>Dark mode (Planned)</li>
<li>Challenge system</li>
<li>QR code sharing</li>
<li>Code readability improvements via CodeMirror</li>
</ul>
</li>
</ul>
