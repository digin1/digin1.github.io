25:T677,<h2 id="project-overview">Project Overview</h2>
<p>GridComposer is a browser-based image layout and design tool that provides an intuitive canvas editor for creating image compositions. Built as a modern alternative to heavyweight design tools, it focuses on fast image arrangement and export workflows.</p>
<h2 id="project-details">Project Details</h2>
<h3>Technologies Used</h3>
<ul>
<li>Next.js 14 (App Router)</li>
<li>Fabric.js (Canvas manipulation)</li>
<li>Tailwind CSS</li>
<li>JavaScript (ES6+)</li>
</ul>
<h3>Key Features</h3>
<ul>
<li><strong>Drag-and-Drop Canvas</strong>: Upload and arrange images freely on a resizable canvas</li>
<li><strong>Alignment &#x26; Distribution Tools</strong>: Snap-to-grid, align left/right/center/top/bottom, distribute evenly</li>
<li><strong>Text Editor</strong>: Add and style text elements with font, size, and color controls</li>
<li><strong>Layer Management</strong>: Bring forward, send backward, lock/unlock layers</li>
<li><strong>Multi-Format Export</strong>: Export compositions as PNG or JPEG with quality controls</li>
<li><strong>Responsive Design</strong>: Works across desktop browsers with touch-friendly controls</li>
</ul>
<h2 id="technical-highlights">Technical Highlights</h2>
<ul>
<li><strong>Fabric.js Integration</strong>: Custom wrapper around Fabric.js for declarative canvas manipulation with React state management</li>
<li><strong>Performance</strong>: Canvas rendering optimised for smooth drag interactions even with multiple high-resolution images</li>
<li><strong>Non-Destructive Editing</strong>: All transformations are non-destructive — original images preserved</li>
