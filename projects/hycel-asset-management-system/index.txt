29:Tc11,<h2 id="project-overview">Project Overview</h2>
<p>An IoT integrated hydrogen leakage detection infrastructure developed for Deakin University (Victoria, Australia) to ensure the safety of the Hycel precinct. The system utilizes Google BigData to visualize real-time sensor data on interactive maps, providing critical monitoring capabilities for hydrogen-related safety systems.</p>
<h2 id="project-details">Project Details</h2>
<h3>Technologies Used</h3>
<ul>
<li>PHP</li>
<li>MySQL</li>
<li>JavaScript</li>
<li>Bootstrap</li>
<li>Google Maps API</li>
<li>BigData Integration</li>
<li>IoT Sensor Integration</li>
<li>SQL</li>
</ul>
<h3>Key Contributions</h3>
<ul>
<li>Developed an interactive mapping system that displays real-time sensor data with color-coded markers</li>
<li>Implemented a sensor information panel that provides detailed metrics including temperature, humidity, sampling frequency, and system status</li>
<li>Created a data visualization system showing warning and danger thresholds for critical measurements</li>
<li>Built a comment/chat system allowing team members to communicate about specific sensor readings</li>
<li>Designed a responsive interface accessible across multiple devices for monitoring on-the-go</li>
<li>Integrated Google BigData for efficient storage and retrieval of large volumes of sensor data</li>
<li>Implemented SQL queries to filter and display relevant sensor information based on location and status</li>
<li>Set up real-time data refreshing to ensure the latest safety information is always available</li>
</ul>
<h3>Features</h3>
<ul>
<li>Interactive map with sensor location markers</li>
<li>Detailed sensor information panels showing:
<ul>
<li>Temperature and humidity readings</li>
<li>Precise GPS location coordinates</li>
<li>Timestamp of readings</li>
<li>Sampling frequency</li>
<li>System ID and manufacturer details</li>
<li>Operating specifications</li>
</ul>
</li>
<li>Color-coded warning system for identifying potential issues</li>
<li>Data visualization tools for monitoring trends</li>
<li>User comment system for team communication</li>
<li>Admin controls for system management</li>
</ul>
<h3>Results</h3>
<ul>
<li>Provided Deakin University with a comprehensive safety monitoring system for hydrogen facilities</li>
<li>Enhanced safety protocols through early detection of potential leaks or abnormal readings</li>
<li>Improved communication among team members regarding sensor status and maintenance</li>
<li>Created a scalable system that can accommodate additional sensors as the Hycel precinct expands</li>
</ul>
<h2 id="process">Process</h2>
<p>This project was developed as an outsourced engagement for Deakin University's Hycel initiative. The development focused primarily on functionality, ensuring reliable data transfer from sensors to the visualization platform. The system was designed to handle large volumes of IoT data while maintaining responsive performance for users monitoring the facility.</p>
