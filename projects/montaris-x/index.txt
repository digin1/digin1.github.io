2b:Taac,<h2 id="overview">Overview</h2>
<p>Montaris-X is a pip-installable desktop ROI editor for scientific microscopy. It is designed for researchers who need local, responsive annotation workflows without relying on large proprietary applications or a fragile chain of manual steps.</p>
<p>Currently under review for listing at the University of Edinburgh's Software Centre for institutional distribution.</p>
<h2 id="problem">Problem</h2>
<p>Microscopy annotation is often trapped between two bad options: heavyweight vendor tooling or improvised research workflows that are hard to standardise. The goal here was to build a local tool that:</p>
<ul>
<li>works well on large scientific images</li>
<li>supports the ROI formats researchers already use</li>
<li>feels responsive enough for real annotation work</li>
<li>is easy to install and distribute</li>
</ul>
<h2 id="what-i-built">What I Built</h2>
<p>Montaris-X includes:</p>
<ul>
<li>ROI drawing and editing tools for practical image annotation</li>
<li>multi-layer ROI management</li>
<li>ImageJ ROI and ZIP import/export</li>
<li>16/32-bit TIFF handling and multi-channel image support</li>
<li>undo/redo and transform operations</li>
<li>an install path simple enough for researchers to adopt</li>
</ul>
<h2 id="technical-decisions">Technical Decisions</h2>
<h3>Native desktop instead of browser</h3>
<p>For this tool, a desktop application was the right choice. The workflow is local, image-heavy, and interaction-intensive. PySide6 provided a reliable base for building something distributable and responsive across platforms.</p>
<h3>Interoperability first</h3>
<p>ImageJ compatibility was non-negotiable. The point was not to create another isolated editor. It was to fit into the tools researchers already trust while giving them a better interface for day-to-day work.</p>
<h3>Distribution</h3>
<p>Publishing on PyPI mattered because it turned the tool into something that could actually be installed, versioned, and shared, rather than staying as a one-off internal script.</p>
<h2 id="constraints">Constraints</h2>
<p>The challenge was to balance a real microscopy feature set with a tool that remained fast enough and simple enough to use in practice. It had to handle scientific image formats and ROI workflows without becoming a bloated desktop application.</p>
<h2 id="outcome">Outcome</h2>
<p>Montaris-X gives researchers a practical local tool for ROI work and reduces dependence on proprietary software for a key part of the microscopy workflow. It also shows a different side of the portfolio: packaged desktop software, not just web applications.</p>
