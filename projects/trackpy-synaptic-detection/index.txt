2b:T9b8,<h2 id="project-overview">Project Overview</h2>
<p>A purpose-built Python pipeline for detecting synaptic proteins in fluorescence microscopy images. Replaces the Java-based TrackMate tool with a pure Python implementation that integrates directly into the lab's existing Python data processing workflows, enabling end-to-end automation.</p>
<h2 id="project-details">Project Details</h2>
<h3>Technologies Used</h3>
<ul>
<li>Python 3</li>
<li>TrackPy (particle detection)</li>
<li>NumPy (numerical processing)</li>
<li>Multiprocessing (parallel tile processing)</li>
<li>tifffile (microscopy I/O)</li>
<li>Matplotlib (visualisation)</li>
</ul>
<h3>Key Features</h3>
<ul>
<li><strong>Adaptive Thresholding</strong>: 65th percentile intensity threshold that adjusts to variable fluorescence levels across tiles</li>
<li><strong>Parallel Processing</strong>: Multi-core processing enabled by default for batch tile analysis</li>
<li><strong>SNR Calculation</strong>: Multiple signal-to-noise ratio methods (local, global, tile-based)</li>
<li><strong>Area Filtering</strong>: Morphological filtering (5-100 px²) to exclude noise and debris</li>
<li><strong>Rich Output</strong>: CSV with 24+ detection properties per particle (x, y, area, mean intensity, max intensity, radius, SNR)</li>
<li><strong>Visualisation</strong>: Optional rendering of first N tiles with detection overlays for quality control</li>
<li><strong>Single-File Deployment</strong>: Standalone script with no complex dependency chain</li>
</ul>
<h3>Performance</h3>
<ul>
<li><strong>10.7% average error</strong> validated against hand-annotated reference samples</li>
<li>Optimised parameters: diameter 7px, minmass 300, separation 11px</li>
<li>Competitive with TrackMate (Java/Fiji) while being fully Python-native</li>
</ul>
<h2 id="technical-highlights">Technical Highlights</h2>
<ul>
<li><strong>TrackMate Parity</strong>: Achieves comparable detection accuracy to the established TrackMate tool without Java/Fiji dependency</li>
<li><strong>Pipeline Integration</strong>: Pure Python enables direct integration with downstream analysis (ROI classification, heatmap generation)</li>
<li><strong>Robust Detection</strong>: Adaptive threshold handles intensity variation across large tiled acquisitions</li>
</ul>
